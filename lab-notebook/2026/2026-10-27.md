## Finding

**Gate A could never have decided anything.** `P` is a low-pass filter of the exposure waveform:
with every source gated by `WS` and a single linear decay, it rises when smoke is on and relaxes
when it is off whatever the epithelial state does, so direction and ordering agreement with the
chip is near-automatic. The one tissue-layer claim it might have tested, A19a's 2:1 ratio, moves `P`
amplitude by ~11 % at the attractor, and the only comparison the pooled n = 3–7 effluent supports
(normalized shape) removes amplitude entirely. A2's co-culture > monoculture ordering holds by
construction because both epithelial `P` sources sit on `E_h`/`E_d`. And a mismatch would be
uninterpretable given dose placement, Calu-3 vs A549, a lumped `P`, pooled effluent and the n.

**Gate D is the only falsifiable test in the plan**, and it decides which paper exists. Spending
the one winter-break build window on the spatial `P` field before knowing D's answer was the wrong
bet in the 2026-10-26 ordering.

## Decisions

- **Gate A is not a gate.** A1–A3 run in November as a descriptive consistency check and as material
  for the UBC ask. A pass does not promote the paper to Original Research; a fail does not cut §2 or
  skip Gate C.
- **Gate order is B → D → C → E.** D (focal arm, `spatial_stats.py` wired, focal vs diffuse at
  matched total damage) runs immediately after B, over winter break; the article-type answer comes
  in January rather than February.
- **C1 (spatial `P` field) is conditional**: only if D passes, time remains, and it is first decided
  what in the tissue consumes `P`. A17's dead-weight condition still holds and EMT stays deferred.
  If `P` output is wanted regardless, use a `P`-analogue readout from existing epithelial state (H5),
  folded into C2.
- **Article type turns on Gate D plus the real-sections question**, as pre-October. Not on Gate A.
- **Unchanged:** ECM cell type 5th / post-paper; ASM and annulus demoted; antioxidant intervention
  cut from the current plan; Gate B in full; bibliography batching.
- **B1 — carry the Eq. 16 M2/`A` enhancement: yes.** The `f_d` the seeding rule tracks is the
  ODE's balance of `e3·WS` creation against *enhanced* repair, so a bare-`e4` tissue rate would make
  per-cell damage persistence inconsistent with the fraction the same ODE prescribes. The factor
  (≈ 2.40 at the attractor → ≈ 8.3e-5 per MCS, mean damaged lifetime ≈ 12,000 MCS) is spatially
  uniform, so it adds no spatial structure — same status as the `S_M2` pedestal, and distinct from
  the v2 multiplicative gain on cell-based secretion. `Ed'` numbering (`e8`, `e9`) used. Switchable
  off with `EPITHELIAL_REPAIR_CARRY_ODE_ENHANCEMENT`.
- **B1 — tissue clock, not the ODE clock**, for the per-hour → per-MCS conversion (A7's
  62.4 s/MCS), because the ODE is consumed as quasi-steady constants (A11) and damage persistence
  on the lattice is a tissue-time quantity. Flag: the two clocks remain unreconciled (`ODE_STEP_SIZE`
  = 1 h/MCS), as already logged in the todo.
- **B2 — 11, the ratio reading of Zajicek (1992)**, not 16–17 (linear density): dimensionless, so
  the µm/px spread and the 10 vs ~6.8 µm width tension cancel out; it is the comparison A18 permits.
- **B4 — the rebaseline is accepted as the standing n = 6 baseline** (−2.5 % mean, see the Gate B4
  section): every pre-registered criterion passed and the pre-stated direction held. The fivefold
  drop in narrowing is recorded as a finding about what controls narrowing, not as a reason to
  revisit the count or re-target §3.5.
- **Flags for validation targets (none changed):** §3.5 lumen is Tier 1 and is being re-measured, not
  re-targeted; §3.4 fibroblast number is an ablation target and B2 changes its `t = 0` value, not its
  criterion; §3.6 focal-vs-diffuse now sits on a damage pattern with a finite lifetime (repair), which
