# 2026-07-21

**Focus:** Get CompuCell3D 4.9.0 installed and working on this machine.

## Did
- Hit a Python version conflict following the SrcBin / 4.9.0 release install docs:
  system Python is 3.14, but CC3D 4.9.0 requires Python 3.12.
- Used the existing miniforge3 install to create an isolated conda env instead of
  touching system Python.
- Installed CC3D 4.9.0 via mamba into that env.
- Hit and fixed a corrupted conda package cache error for `debugpy`
  (`Cannot find a valid extracted directory cache`) by running
  `conda clean --packages --tarballs -y` and retrying.
- Verified `import cc3d` reports version 4.9.0, and `cc3d-player5.exe` /
  `cc3d-twedit5.exe` are present in the env's `Scripts` folder.
- `conda activate` didn't work in git bash out of the box (only PowerShell had been
  `conda init`'d); fixed by running `conda init bash` once.
- Installed the CC3D Demos (SrcBin step 5): pulled `CompuCell3D/core/Demos` from the
  CompuCell3D repo via a git sparse-checkout at the commit pinned in the SrcBin docs,
  instead of the browser-based download-directory.github.io step.
- First placement was wrong (`envs\cc3d_490\Demos`) and the Player couldn't find it.
  `DemoBrowser.py`'s `getDemoRootPath()` walks up from the installed `cc3d` package
  location looking for a folder literally named `CompuCell3D` containing a `Demos`
  subfolder — a bare `Demos` folder anywhere doesn't get picked up. Corrected to
  `envs\cc3d_490\CompuCell3D\Demos`; confirmed Demo Browser finds it in the Player.

## Decisions
- CC3D lives in its own conda env, `cc3d_490` (Python 3.12), rather than as a
  standalone installer or a system Python package. Activate with
  `conda activate cc3d_490` before running the Player, Twedit5, or headless scripts.
- Demos must live at `<env root>\CompuCell3D\Demos` (not `<env root>\Demos`) for the
  Player's Demo Browser to auto-discover them — a quirk of `DemoBrowser.py`'s parent-
  directory search, not documented in the SrcBin instructions.

## Commands / code run
```
conda create -n cc3d_490 python=3.12 -c conda-forge -y
conda activate cc3d_490
conda install -c conda-forge mamba -y
mamba install -c conda-forge -c compucell3d compucell3d=4.9.0 -y
# (after first attempt failed on a stale package cache)
conda clean --packages --tarballs -y
```
