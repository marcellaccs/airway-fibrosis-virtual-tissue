## Results / observations

- **What depends on `C` today.** Sources: XML `SecretionOnContact` myofibroblast on Medium 0.08;
  Python epithelial basal secretion 0.01 per wall-side pixel. Consumers: myofibroblast λ_volume =
  12 · (1 + 2 `c_norm`) and `targetVolume` (the latter already 0 under ECM cells, 11-04);
  fibroblast λ_volume = 8 · (1 + `c_norm`); the Phase 3 `C` MMP-decay term. Readouts:

- **Size of the stiffening that goes:** Gate B4 mean `c_norm` at myofibroblast COMs 0.08–0.20, so
  λ ≈ 14–17 against the base 12 (≈ 31 at the maximum `c_norm` 0.78). Under MMP + `C` term it was
  already nearly gone near the sheet (mean `c_norm` 0.019 at 3k).
- **Found in passing, base model, not changed:** the fibroblast `c_norm` stiffening is live only
  for dividing fibroblasts. `update_fibroblast_state` sets λ_volume = 8 · (1 + `c_norm`), and for
  every fibroblast that is not dividing `activate_fibroblast` then overwrites it in the same MCS
  with 8 · (1 + activation progress). `activate_fibroblast` takes `C` as an argument and does not
  use it. The base is frozen, so this is a note for the Phase 5 change list, not a fix.
- **Implementation constraint for Phase 4:** the myofibroblast `C` source is an XML literal, which

  id alone leave the off twin identical); fallback: the field runs unread.

  cells, ECM pixel fraction with them), so cross-condition matrix comparisons are ordinal.

- **The answer to the question:** at `G` = 0.001 the model makes 13 / 84 / 350 myofibroblasts at
  5k / 10k / 20k, against 26 / 47 / 59 on the current base. Fewer for the first ≈ 7,000 MCS (43 against 45 at
  7k), then more, about six times more by 20k and still rising (the count doubles about every
  5,000 MCS).
- **Why.** At 0.1 the myofibroblasts lift band `G` above the 0.45 activation gate everywhere, the
  whole fibroblast pool converts by ≈ 6k, and since myofibroblasts do not divide the population
  is capped (B4 n = 6: 42–62). That saturating rate was the model's only brake on proliferation.
  At 0.001 band `G` stays at 0.19–0.31, conversion is local, a pool of 30–70 fibroblasts persists
  and keeps dividing: `update_fibroblast_mitosis` has no contact inhibition and no carrying
  capacity, only the `G` gate (always open, next bullet) and space. Mesenchymal cells total 24 / 44 / 125 / 250 / 419 at
  3k / 5k / 10k / 15k / 20k, until the band is 96.5 % cells with no ECM in it.
- **The mitosis gate does not gate** (diagnostic copy, sampled every 500 MCS to 10k; its
  population lines are identical to copy 1, so the prints changed nothing). Every fibroblast reads
  local `G` ≥ 0.225 at every sample from MCS 500 on: range 0.27–0.48, median 0.31 until 1,500 and
  0.40–0.43 from 4k, while the band mean is 0.19–0.24. The difference is the cell's own secretion
  (0.005 per pixel) and its neighbours'. It already holds with nine scattered fibroblasts at
  MCS 500, so it is true of the current base as well (in B4 the first division is at MCS 1,828,
  one 1,731-MCS cycle after the start). The fibroblast median sits just under the 0.45 activation
  gate, with 0–9 fibroblasts above it at any sample: at this rate conversion happens where
  fibroblasts crowd each other, not where the epithelium is damaged.
- **The source order is inverted at 0.001.** Myofibroblasts read a median local `G` of 0.26–0.33,
  below the fibroblasts, because a myofibroblast then secretes five times less `G` per pixel than
  a fibroblast (0.001 against 0.005).
- **Where the cells are (to 10k).** No fibroblast is in the interface strip (y ≥ 62) at any
  sample; the fibroblast median is y 14–27 in a band that spans y 4–71, about half of them below
  y 20, where boundary recruits enter. Two or three myofibroblasts are at the interface throughout
  (the early ones, converted next to the sheet); the rest are deep (median y 15–27).
- **Where the myofibroblasts sit (`G` 0.001).** In the interface strip (y 62–71): 3 / 2 / 42 at
  5k / 10k / 20k (B4: 5 / 7 / 6); strip occupancy 5.6 % at 10k and 79.6 % at 20k (B4 8.7 % at
  both). The band fills from below and reaches the sheet only in the last ≈ 2,500 MCS, which is
  when the lumen loss comes (−2.6 % at 17.5k, −8.6 % at 20k). Band `C` falls after 15k (3.86 →
  2.04) because the Medium-contact secretion stops once the cells are packed.
- **The activation-rate copy is worse, not better.** With conversion slowed to the literature
  rate no fibroblast converts before MCS 7,800, the pool divides unchecked (629 fibroblasts), and
  the sheet is pushed up (sheet yCOM mean 78.0 at 5k, 84.1 at 7.5k, 92.8 at 20k; lumen −8 % already
  at 3k with only 27 fibroblasts, 2,757 px at 7,000, 0 px from 7,400). The early loss with few
  cells suggests fibroblasts that never convert keep chemotaxing into the sheet (myofibroblasts
  have chemotaxis λ = 0); I did not test that. Read as a direction, not a number: `G_sat` is
  assumed, and the run is past any regime the model was built for.
- **Budget arithmetic (current base).** Myofibroblast-MCS over 20k for the six B4 replicates:
  522,200–835,300 (mean 732,100; seed 200: 790,550, a little above the 11-04 three-point estimate
  of 745,000). At `ECM_BUDGET_INCREMENT` = 0.08 px/MCS that is 41,800–66,800 px, 3.6–5.8× the
  ≈ 11,600 px of free band. The increment that nominally fills the free band exactly by 20k is
  0.014–0.022 px/MCS (0.016 at the mean); half the band, 0.007–0.011. Nominal because the budget
  only accrues on Medium contact and MMP removes ECM near the sheet.

### Recommendation (Marcella's decision; nothing applied)

- **Do not move plan §6 item 7 ahead of Phase 4. Keep it in Phase 5 and lower
  `ECM_BUDGET_INCREMENT` for Phase 4.** The reason for moving it was to have fewer producers; the
  run shows the change as pre-registered gives more of them and fills the band with cells before
  any matrix exists, so it would make the packing problem worse and would not be a usable
  criterion-1 reference. The current base is the stable one (42–62 myofibroblasts, capped by
  ≈ 6k, band 15 % occupied).
- **Budget value, first pass: about 0.01 px/MCS** (one 36-px ECM cell per myofibroblast per
  ≈ 3,600 MCS ≈ 2.6 days; nominally 5,200–8,400 px over 20k, 45–72 % of the free band). A free
  parameter; Gate D can scan it. The value is hers to set.
- **New decision this run raises, before Phase 5:** item 7 as written (lower myofibroblast `G`,
  slow the activation rate) removes the model's only brake on fibroblast proliferation, and each
  half makes the overgrowth worse on its own evidence here. It needs a third element, a limit on
  proliferation. Options, none built or tested: (i) contact inhibition, the mitosis clock accrues
  only with enough free (Medium) boundary or below a local cell density; (ii) a mitosis gate above
  the level a fibroblast's own secretion produces (it would have to sit above ≈ 0.48, which is
  above the 0.45 activation gate, so the two gates would need rethinking together); (iii) lower
  fibroblast `G` secretion (0.005) so a fibroblast does not hold itself above the gate. Which
  mechanism is biology to choose, with a literature check. The same list should carry the
  inverted source order (myofibroblast 0.001 below fibroblast 0.005).
