# literature/

- `references.bib` — BibTeX for all cited work. Export entries from **Zotero**
  (right-click item → Export Item → BibTeX) and paste them here.
- `notes/` — your reading notes (one markdown file per paper, named by cite key).

Article **PDFs stay in Zotero** and are gitignored — do not commit them (size + copyright).
