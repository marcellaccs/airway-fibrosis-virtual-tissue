# model/

- `ode/` — the published Tellurium ODE model (epithelial, macrophage, and full model
  notebooks). This is the **signal-generating layer** for the tissue model.
  Copy the notebooks from the research Drive `Math Modeling in Toxicology/` here,
  and clear notebook outputs before committing.
- `cc3d/` — the CompuCell3D virtual-tissue model. Start from the existing prototype in the
  research Drive: `Math Modeling in Toxicology/Old CC3D M1 to M2 files/`
  (M1_M2 steppables, XML, parameters). Copy the project in, then develop here.
